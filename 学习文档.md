## 1. 数据库设计：5+2 张新表

### 核心表：knowledge_chunk

```python
# backend/open_webui/models/knowledge.py
class KnowledgeChunk(Base):
    __tablename__ = 'knowledge_chunk'
    id = Column(Text, unique=True, primary_key=True)
    knowledge_id = Column(Text, ForeignKey('knowledge.id', ondelete='CASCADE'), nullable=False)
    file_id = Column(Text, ForeignKey('file.id', ondelete='CASCADE'), nullable=False)
    chunk_index = Column(BigInteger, nullable=False)
    content = Column(Text, nullable=False)
    token_count = Column(BigInteger, nullable=True)
    meta = Column(JSON, nullable=True)  # 关键词、问题、分块方式等
    content_hash = Column(Text, nullable=True)

    __table_args__ = (
        UniqueConstraint('file_id', 'chunk_index', name='uq_knowledge_chunk_file_index'),
    )
```

**踩坑**：`UNIQUE(file_id, chunk_index)` 约束导致 merge/split 的 UPDATE 中间态冲突。解决：用 `+10000` 偏移法。

### 书籍分块（章节识别）

```python
def book_chunking(content, params):
    chapter_pattern = re.compile(
        r'^(第[一二三四五六七八九十百千\d]+[章节部篇]|Chapter\s+\d+)',
        re.IGNORECASE
    )
    chunks = []
    current_chapter = None
    current_section = []
    for line in content.split('\n'):
        if chapter_pattern.match(line.strip()):
            if current_section:
                chunks.append({'content': '\n'.join(current_section), 'metadata': {...}})
            current_chapter = line.strip()
            current_section = [line.strip()]
        else:
            current_section.append(line.strip())
    return chunks
```

### 表格分块（CSV→键值对）

```python
def _chunk_csv_table(lines):
    headers = [h.strip() for h in lines[0].split(',')]
    for i in range(1, len(lines)):
        values = [v.strip() for v in lines[i].split(',')]
        kv = [f"{h}: {v}" for h, v in zip(headers, values)]
        chunks.append({'content': '\n'.join(kv), 'metadata': {...}})
```

### 合并分块（核心难点）

```python
# backend/open_webui/routers/knowledge.py
@router.post('/{id}/chunks/merge')
async def merge_knowledge_chunks(...):
    # 1. 删除旧分块
    await db.execute(sa_delete(KnowledgeChunk).where(KnowledgeChunk.id.in_(old_ids)))
    db.add(merged_chunk)

    # 2. 偏移+10000避开约束冲突
    await db.execute(text("UPDATE knowledge_chunk SET chunk_index = chunk_index + 10000 "
        "WHERE knowledge_id = :kid AND file_id = :fid"))

    # 3. 重新编号
    result = await db.execute(sa_select(KnowledgeChunk)...)
    for i, c in enumerate(result.scalars().all()):
        c.chunk_index = i
    await db.commit()
```

**关键教训**：SQLite 不支持 DEFERRABLE 约束，批量 UPDATE 时必须保证中间态也不违反 UNIQUE。

```python
@router.get('/{id}/progress/stream')
async def stream_processing_progress(...):
    async def event_generator():
```

```python
@router.post("/_workflows/exec")
async def exec_workflow(request, user, db):
    variables = {"query": q}
    async def event_generator():
        for step in steps:
            yield "data: " + json.dumps({"step": ..., "status": "running"}) + SSE

            if step.agent_role == "retriever" and step.knowledge_id:
                # 真实检索
                r = await query_collection(collection_names=[step.knowledge_id], ...)
                docs = r["documents"][0][:3]
                # 查文件名
                f = await Files.get_file_by_id(doc_meta["file_id"])
                output = f"### Document: {f.filename}\n{doc_content}"
            else:
                # 调用 DeepSeek LLM
                async with httpx.AsyncClient(timeout=60) as client:
                    resp = await client.post(
                        f"{api_url}/chat/completions",
                        headers={"Authorization": f"Bearer {api_key}"},
                        json={"model": "deepseek-chat", "messages": [{"role": "user", "content": prompt}]}
                    )
                    output = resp.json()["choices"][0]["message"]["content"]
            # 变量传递到下一步
            if step.output_var:
                variables[step.output_var] = output
            yield "data: " + json.dumps({"output": output[:400]}) + SSE
    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

**关键点**：
- 检索员：`query_collection()` + `Files.get_file_by_id()` 查文件名
- 分析员/汇报员：`httpx` 直接调 DeepSeek Chat API
- API Key：`load_dotenv(override=True)` 强制覆盖加载
- 变量传递：output_var → variables dict → input_var 替换到 prompt

```python
@router.post('/{id}/snapshots/{sid}/rollback')
async def rollback_knowledge_snapshot(...):

    # 2. 清除当前状态
    await db.execute(sa_delete(KnowledgeChunk).where(...))
    await db.execute(sa_delete(KnowledgeFile).where(...))
    # 3. 恢复分块和文件关联

        db.add(KnowledgeFile(...))
```

**设计权衡**：快照只存 file_id 引用不存文件内容。配合 Unlink Only 按钮（`delete_file=false`）确保文件不被物理删除。

## 9. 踩坑精华

| 问题 | 解决方案 | 教训 |
|---|---|---|
| SQLite UNIQUE 约束中间态冲突 | +10000 偏移 + 重新编号 | 批量 UPDATE 必须考虑中间态 |
| `/{id}` 先于 `/_workflows` 匹配 | 路由顺序放到前面 | FastAPI 路由按注册顺序匹配 |
| `load_dotenv()` 不覆盖已有值 | `override=True` | 框架自己加载过 env 时需注意 |
| Agent 步骤间变量不传递 | 自动收集前序输出注入 prompt | 声明 ≠ 使用，prompt 要显式引用 |
| `git checkout` 连锁还原 | 追加式修改（文件末尾） | 避免中途修改，只追加新功能 |
| chunk_id 重复导致 Svelte 报错 | `result-{i}-{hash[:8]}` | 列表渲染 key 必须唯一 |
| `\n\n` 在 Python 文件写入时被解释 | `chr(10)+chr(10)` | 多层字符串转义用 chr() 最安全 |
